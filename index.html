DATA STORAGE: SQLite otomatis menyimpan semua parameter termasuk suhu, kelembapan, tegangan sensor, dan Rs/R0, meskipun tidak tampil di grafik. CSV sesi dan CSV gabungan menggabungkan PM + Gas per detik berdasarkan timestamp pengukuran, tanpa kolom device, serta menyimpan session_name dan label. Bila salah satu sumber tidak tersedia untuk detik tersebut, kolomnya dibiarkan kosong; CSV mentah tetap tersedia untuk audit. Record otomatis berhenti sesuai durasi atau manual lewat STOP. Endpoint ESP: /api/ingest, port 8787. Gunakan jaringan LAN tepercaya.

Pengaturan Aplikasi

Tema tampilan, informasi penyimpanan, dan pengelolaan data lokal.

01 / Tema Tampilan

Pilih tema terang atau gelap. Pilihan tersimpan di browser ini dan tidak memengaruhi pembacaan sensor.

02 / Folder Data

Semua file disimpan pada data/ di folder instalasi, terdiri dari monitoring.sqlite3, file dukungan SQLite, dan records/ untuk CSV sesi. Folder data tidak ditimpa saat update installer.

03 / Hapus Semua Data Lokal

Tindakan permanen: menghapus pembacaan, riwayat sesi, perubahan label, CSV sesi, dan cadangan migrasi lokal. Tidak menghapus data di microSD ESP atau Supabase. Hentikan RECORD terlebih dahulu.
